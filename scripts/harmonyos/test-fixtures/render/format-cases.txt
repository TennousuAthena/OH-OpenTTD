# format-cases.txt — RGBA/BGRA conversion vectors.

# A screen pixel carries channels (r,g,b,a). In _screen memory (ColourBGRA on
# little-endian) the byte order is b,g,r,a. Surface byte order depends on the
# OH_NativeBuffer_Format:
#   BGRA_8888 -> b g r a   (direct copy, no conversion)
#   RGBA_8888 -> r g b a   (red/blue swap during copy)
#
# Each line: r g b a   bgra_bytes(hex)   rgba_bytes(hex)
