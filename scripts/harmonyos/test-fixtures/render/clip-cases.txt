# clip-cases.txt — dirty-rectangle clipping scenarios against a surface.
#
# Each block:
#   surface <w> <h>                surface pixel size
#   dirty   <l> <t> <w> <h>        pre-union dirty rect (may extend OOB)
#   expect  <l> <t> <r> <b>        expected clip (half-open, within surface)
#   expect empty                    expected empty clip -> no flush
# '#' starts a comment; blocks separated by blank lines.
#
# Clip = intersect(union, [0,w)x[0,h)); fully-outside rects clip to empty.
