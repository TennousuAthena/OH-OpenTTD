# 15.3-harmonyos.2

OpenTTD 15.3 鸿蒙移植版，应用包名 **`moe.kiwi.openttd`**，versionCode **15000302**。
面向 HarmonyOS 平板和二合一设备，单个 HAP 包含 **arm64-v8a / x86_64**。
使用 DevEco Studio 26 / HarmonyOS 7 API 26 构建，最低兼容 API 20。

## 本次更新

- 修复鼠标滚轮上下方向都被识别为向上的问题。普通滚轮事件的捏合值为 0，
  现在保留实际滚动方向；水平滚轮和空事件也得到正确处理。
- 应用包名统一为 `moe.kiwi.openttd`，更新匹配的签名 Profile。
- 应用和原生显示版本统一为 `15.3-harmonyos.2`，联机协议版本保持 **15.3**。
- 保留既有 GPU 上传、调色板动画、输入队列、垂直同步和音乐线程性能优化。
  Release 构建保持 `-O2 -g`，默认关闭性能诊断和高频日志。

## 验证范围

滚轮修复已通过真实输入桥接和输入规范的回归检查，并在 HarmonyOS 7 / API 26
MateBook 真机上验证地图放大/缩小及列表上下滚动。两个 ABI 均编译并核验优化
参数和 Build ID；x86_64 尚未进行真机运行验证。性能记录见
[移植记录](../port-notes.md)和[性能文档](../performance.md)。

## 下载与安装

- `*-signed.hap`：使用 `moe.kiwi.openttd` 的 **debug Profile** 签名，
  仅能安装到该 Profile 已登记的设备。
- 另一个 `.hap`：相同内容的未签名包，其他设备需用自己的证书和匹配
  `moe.kiwi.openttd` 的 Profile 重新签名。
- `*-src.tar.gz`：对应源码。Release 同时提供符号、SBOM、许可声明和 SHA256 校验值。

包名从 `org.openttd.openttd` 改为 `moe.kiwi.openttd`，系统会将其识别为新应用。
旧应用的存档和配置不会自动迁移；请保留旧应用，先导出需要的存档。

本次发布位于 GitHub，不是 AppGallery 上架包。生产分发需要 release 证书及 Profile。
